# Cryptography-Aware Digital Forensics Framework

## Overview
This project is a digital forensics system that detects encrypted files, verifies integrity using SHA-256 hashing, analyzes metadata, and generates forensic reports.

## Features
- Evidence Scanning
- Entropy-Based Encryption Detection
- SHA-256 Hash Verification
- Metadata Analysis
- Timeline Reconstruction
- Forensic Report Generation
- Web Dashboard (Streamlit)

## Technologies Used
- Python
- Streamlit
- Matplotlib

## How to Run
```bash
streamlit run forensic_dashboard.py
